# Profile Picture Prompts

Circular profile avatars rendered in the unified painterly-anime cel-shaded card art style shared across the project (niji 6, YGO secret rare / Pokémon illustration rare composition, bold ink outlines thick to thin, visible brushwork). **Every set avatar locks to that set's exact canonical palette** as established in its dedicated set prompt file — no foreign hues are allowed to bleed into another set's identity.

All prompts use `--ar 1:1 --niji 6 --stylize 900`.

**Framing rule for every prompt:** subject is centered with radial composition, the critical motif occupies the inner 75% of the frame, and a set-specific halo / corona / mandorla fills the outer 25% so a circular crop never clips the face or core sigil — the corners that get masked are designed to fade gracefully into the round border.

---

## Notes on Use

- **Palette discipline:** Every set avatar opens with a `palette lock:` clause copied verbatim from that set's canonical prompt file. This is intentional — Midjourney respects palette locks much more strongly than color suggestions, and it guarantees a Death-flamed Hell PFP never bleeds into Pyroabyss territory, a Snowbound Voltage PFP never picks up Heavenly Light gold, etc.
- **Style consistency:** Every prompt shares the global render direction (`niji 6`, painterly anime, cel-shaded, bold ink outlines thick to thin, visible brushwork, YGO secret rare / Pokémon illustration rare composition) so the gallery reads as one art set even though palettes differ wildly.
- **Circular crop safety:** The phrase **"framed for circular crop, fills 75% of frame"** keeps faces and core motifs safely inside the circular mask while the outer 25% halo / corona is designed to survive masking as a graceful border.
- **Boss defeat gallery** uses each boss's own set palette rather than a uniform Eternity's Wake monochrome, so the 32 trophies read as a diverse hall of unique encounters rather than a matching series. Two bosses per set are featured — the most iconic and the most visually distinct.
- **Default sigil gallery** uses all sixteen set palettes so the starter wheel reads as one sigil per set without requiring any unlock.
