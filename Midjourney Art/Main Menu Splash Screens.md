# Main Menu Splash Screens

> Legacy concept catalog, not the current runtime unlock specification. The active selectable reward slots use full Eternal/Infinite set-ownership gates, not these older first-acquisition concepts. Forge cosmetic achievements and installed filenames are defined in [Custom Main Menu Backgrounds](./Custom%20Main%20Menu%20Backgrounds.md). The Pyroabyss set art brief has been replaced by [Intensity Set Prompts](./Intensity%20Set%20Prompts.md); its white/black/gold 29-card roster is a proposal, not live content. Older set names and chrome-only treatments below remain historical references and do not override those current briefs.

Three cinematic splash screen art prompts per card set — displayed on the main menu when the player hits a rarity milestone acquisition for the first time. All prompts use `4k, high quality --ar 16:9 --niji 6 --stylize 900`.

**Tier escalation:**
- **First Eternal** — The set's world erupts and manifests around the card; an epic environmental revelation of belonging.
- **First Infinite** — The card exceeds the set's elemental palette; chrome-silver transcendence rewrites the world around it.
- **First Transcendent** — The card IS the world; a cosmological impossibility where the set's entire visual identity exists because of this one card.

**Composition rule on every prompt:** Widescreen cinematic 16:9. Strong negative space in one region for title treatment. The card itself is always the single most luminous or most compositionally weighted object in the frame. Set palette locked to that set's canonical colors — the Infinite tier allows chrome-silver and polished-platinum bleed at the card's core, the Transcendent tier integrates it fully.

## Notes on Use

- **Aspect ratio:** All prompts use `--ar 16:9` for widescreen cinematic display as main menu splash overlays.
- **Title treatment:** Every prompt reserves a specific region for title/text overlay — described in the prompt as "negative space for title." The region varies by composition to avoid clashing with the focal element.
- **Tier escalation logic:** Eternal = the world erupts to receive the card. Infinite = the card exceeds the world and rewrites it from the inside out (chrome-silver and polished-platinum bleed from the card's core into the set's palette). Transcendent = the card IS the world; the set's entire cosmology exists because of it.
- **Chrome rule:** The Infinite tier introduces chrome-silver and polished-platinum as the color of transcendence — these are not in any set's canonical palette but bleed in from the card's core at Infinite tier. At Transcendent tier, the chrome may fully dominate or integrate. This matches the `Infinite` avatar aesthetic from Profile Picture Prompts.
- **Palette discipline:** Every set opens each of its three prompts with that set's strict palette lock verbatim, so Midjourney cannot bleed palettes between sets even in the Transcendent tier where the scale becomes cosmic.
- **Composition scale per tier:** Eternal = environmental mid-to-close shot (the world around you). Infinite = the world changing at architectural or atmospheric scale. Transcendent = cosmological / planetary / galactic scale.
